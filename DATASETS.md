# Dataset provenance, licenses, and local preparation

X-MAS uses existing evaluation datasets. The JSON files in this repository are sampled or reformatted copies; they are not relicensed by this project. Users must follow each upstream dataset's license and access terms. License labels below reproduce the metadata declared by the linked upstream release as checked on 2 August 2026; they are not a legal determination about separately copyrighted source material. "Not declared" means that the linked upstream release does not state a dataset license, not that the data are unrestricted.

Unless a row says otherwise, local preparation converts records to the common `query`, `gt`, `tag`, and `source` schema and applies the original deterministic shuffle/sample procedure with seed 2024. Counts refer to the JSON records used by the released experiments.

## GPQA local preparation

GPQA's provider requires users to request access and asks that benchmark examples not be posted publicly. The repository therefore does not include GPQA question records. After access is granted, download `gpqa_main.csv` and `gpqa_diamond.csv` from the official source and run the command in the README. The preparation script validates the official column names, formats the multiple-choice prompt used in the experiments, and deterministically shuffles records with seed 2024. It prints only output paths and record counts, not question text.

## Redistribution note

Entries marked "license not declared" require particular care: public download availability alone does not grant redistribution permission. This manifest records that uncertainty rather than treating those datasets as unrestricted. If an upstream license or access term changes, the upstream source controls.
